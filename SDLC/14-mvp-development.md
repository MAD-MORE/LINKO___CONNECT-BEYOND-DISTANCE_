# Phase 14 — MVP Development

## Objective
Prove the hardest technical hypothesis with the smallest production-minded product.

## MVP scope

- Android application
- Authentication
- Device registration
- Friend relationship
- Connection request
- Provider approval
- Android VPN permission
- Secure tunnel
- Provider traffic forwarding
- Receiver routing
- Session status
- Usage counters
- Disconnect
- Basic relay fallback
- Security controls

## Explicitly deferred

- Large social graph
- Complex rewards economy
- Enterprise features
- Global relay fleet
- Advanced analytics
- Large-scale billing catalog

## MVP success test

Two authorized Android devices, on potentially different networks and far apart, can establish a secure session, route defined Internet traffic through the Provider, display usage, and terminate cleanly.

## Exit criteria

MVP works on real Android devices, passes core security tests, and has no unresolved critical blocker to controlled beta testing.
