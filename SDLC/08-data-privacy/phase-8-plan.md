# Phase 8 — Data & Privacy Implementation

## Status
DESIGN BASELINE COMPLETE; implementation and compliance evidence remain required.

## Scope
Database schemas, migrations, retention, deletion, access control, audit records, analytics minimization, backup protection, export/correction workflows, and privacy operations.

## Rules
Collect the minimum data needed; do not persist forwarded traffic payloads; classify network metadata; protect backups; propagate deletion; and keep telemetry privacy-safe.

## Gates
Schema tests, migration rehearsal, restore tests, deletion verification, access-control tests, privacy review, and data-flow inventory must pass before production readiness.
