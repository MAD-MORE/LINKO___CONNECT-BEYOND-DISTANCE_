# Phase 23 — Observability

## Objective
Know when Linko is healthy, failing, expensive, or being abused.

## System metrics

- Active users
- Active sessions
- Successful/failed connections
- Connection establishment time
- Latency
- Throughput
- Relay bandwidth
- CPU/memory
- Database latency
- Error rates

## Business metrics

- DAU/MAU
- Retention
- Activation
- Free-to-paid conversion
- MRR
- Churn
- Revenue per user
- Infrastructure cost per user

## Reliability

Use structured logs, metrics, traces, alerting, dashboards, and incident runbooks. Never log secrets or unnecessary sensitive traffic information.

## Exit criteria

Production has actionable dashboards, alerts for critical failures, cost visibility, and documented incident response.
