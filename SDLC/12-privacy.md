# Phase 12 — Privacy

## Objective
Make Linko useful without collecting more information than necessary.

## Principles

- Data minimization
- Purpose limitation
- Clear consent
- Transparent disclosures
- Retention limits
- User access/deletion workflows
- Secure processing

## Traffic privacy

Linko should not store browsing contents as a default requirement. Usage accounting can record metadata such as session duration and transferred bytes without retaining unnecessary browsing content.

## User controls

- View account data
- Delete account
- Revoke devices
- Revoke friendships
- End sessions
- Manage notifications

## Exit criteria

Privacy architecture, retention rules, user controls, privacy disclosures, and data-deletion workflows are documented and tested.
